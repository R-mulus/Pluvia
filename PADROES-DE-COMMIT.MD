# Padrões de Commits

Este documento descreve as convenções de prefixos para mensagens de commit no projeto.

- **add**: Commit genérico para quando houveram muitas modificações/adições, inviabilizando o uso de apenas um outro prefixo.
- **feat**: Adição de funcionalidade.
- **fix**: Correção de bug.
- **refactor**: Melhoria ou modificação na estrutura.
- **docs**: Atualizações na documentação (ex: README.md).
- **style**: Mudanças de estilo e formatação.
- **test**: Adição, atualização ou correção de testes unitários ou de integração.
- **chore**: Tarefas rotineiras, atualização de dependências ou arquivos de configuração (ex: .gitignore).
- **perf**: Refatoração focada na performance.
- **build**: Mudanças que afetam o sistema de build, empacotamento ou dependências externas.
- **ci**: Mudanças em arquivos e scripts de configuração de Integração Contínua (ex: GitHub Actions).
- **revert**: Reverte um commit anterior.
