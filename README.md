# Pluvia
Repositório direcionado para o desenvolvimento do app Pluvia, para o Projeto Integrador IV do curso de Sistemas de Informação, UNIPAM.

# Como Rodar o Projeto

1. Rode "npm i" **na raiz do projeto**
2. Rode a task "Iniciar Servidores" OU rode o comando "npm run dev" **na raiz do projeto**

# Comandos Úteis (rode os comandos na RAIZ)

- **Atualizar arquivo de tipos do banco de dados**: npm run update-types
